# trmnl-maps

Static image host for a family of self-contained TRMNL e-ink plugins, served via GitHub Pages.

- `map*.jpg` — **Relief** (formerly *I Fucking Love Maps*): grayscale detail crops of
  hachured relief, glacier contours, coast surveys and volcano maps. Source: David Rumsey
  Map Collection, David Rumsey Map Center, Stanford Libraries — CC BY-NC-SA 3.0, see
  [LICENSE.md](LICENSE.md). Regenerate with `prerender_pool.py` in the workspace.
- `art/` — Daily Sublime (Met Open Access, CC0).
- `weird/` — personal pool, not published.
