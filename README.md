# trmnl-maps

Static image host for the TRMNL e-ink plugin **I Love Maps**, served via GitHub Pages.

- `map*.png` — **I Love Maps**: grayscale detail crops of
  hachured relief, glacier contours, coast surveys and volcano maps. Source: David Rumsey
  Map Collection, David Rumsey Map Center, Stanford Libraries — CC BY-NC-SA 3.0, see
  [LICENSE.md](LICENSE.md). Regenerate with `prerender_pool.py` in the workspace.
